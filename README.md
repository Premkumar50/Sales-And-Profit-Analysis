# 📊 Sales & Profit Analysis

## 📌 Project Overview

This project presents a **Sales & Profit Analysis Dashboard** created using **Microsoft Excel**.

The main objective of this project is to analyze sales and profit performance using data cleaning, Pivot Tables, charts, and an interactive Excel dashboard.

The dashboard provides a clear visual overview of sales, profit, customers, product categories, states, and monthly performance.

---

## 🎯 Project Objective

The main objectives of this project are:

- Analyze overall sales and profit performance.
- Identify the best-performing product categories.
- Analyze profit trends over different years.
- Identify states contributing to sales.
- Identify customers generating the highest profit.
- Analyze monthly sales performance.
- Transform raw data into meaningful business insights.
- Present the analysis through an easy-to-understand dashboard.

---

## ❓ Key Business Questions

This project focuses on answering the following business questions:

1. **What is the total sales and total profit generated from the business?**

2. **Which product categories generate the highest sales?**

3. **How does profit change from year to year?**

4. **Which states contribute the most to overall sales?**

5. **Which customers generate the highest profit?**

6. **Which months have the highest and lowest sales performance?**
